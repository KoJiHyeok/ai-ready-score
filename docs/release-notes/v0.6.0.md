# v0.6.0

## English

v0.6.0 adds root-level ignore support for projects that need to exclude generated or local-only entries from AI-readiness scans.

### Added

- Added repeatable `--ignore <pattern>` CLI support.
- Added config `ignore` array support.
- Added applied ignore pattern reporting to text, JSON, and Markdown output.
- Added validation so ignore patterns stay root-level and cross-platform.

### Notes

- Ignore matching is root-level only in this release.
- Exact names such as `dist` and `.env` are supported.
- Simple `*` wildcard patterns such as `*.log` are supported.
- The built-in 100-point scoring rubric is unchanged.

## 한국어

v0.6.0은 생성된 항목이나 로컬 전용 항목을 AI 준비도 검사에서 제외할 수 있도록 루트 항목 ignore 기능을 추가합니다.

### 추가됨

- 반복 가능한 `--ignore <pattern>` CLI 옵션을 추가했습니다.
- 설정 파일의 `ignore` 배열을 지원합니다.
- 적용된 ignore 패턴을 text, JSON, Markdown 출력에 표시합니다.
- ignore 패턴이 루트 항목 기준과 크로스 플랫폼 동작을 유지하도록 검증을 추가했습니다.

### 참고

- 이번 릴리스의 ignore 매칭은 루트 항목만 지원합니다.
- `dist`, `.env` 같은 정확한 이름을 지원합니다.
- `*.log` 같은 단순 `*` 와일드카드 패턴을 지원합니다.
- 기본 100점 점수 기준은 변경되지 않았습니다.
