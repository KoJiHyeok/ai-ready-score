# v0.4.0 - Completion Workflow Documentation

This release documents the required completion and release workflow for future Codex work on `ai-ready-score`.

## Changes

- Added a required completion workflow to `AGENTS.md`.
- Documented that normal development tasks must include implementation, tests, validation, artifact cleanup, commit, push, and a final summary.
- Added a release-only workflow for version bumps, tags, npm publishing, and published package verification.
- Clarified that `npm publish` must only run when the user explicitly requests a release or publish task.
- Reinforced preservation requirements for Korean and English output, JSON output, Markdown output, `--init`, and `--min-score`.
- Updated `CHANGELOG.md`, `docs/release-checklist.md`, and this release note for v0.4.0.

## Validation

```bash
npm test
npm run check
npm pack --dry-run
```

## Publishing

This release is intended to be published to npm as `ai-ready-score@0.4.0`.

# v0.4.0 - 완료 워크플로우 문서화

이번 릴리스는 향후 `ai-ready-score`에서 Codex가 작업할 때 따라야 하는 필수 완료 및 릴리스 워크플로우를 문서화합니다.

## 변경 사항

- `AGENTS.md`에 필수 완료 워크플로우를 추가했습니다.
- 일반 개발 작업에는 구현, 테스트, 검증, 산출물 정리, 커밋, push, 최종 요약이 포함되어야 한다고 문서화했습니다.
- 버전 변경, 태그, npm publish, 배포된 패키지 검증을 위한 릴리스 전용 워크플로우를 추가했습니다.
- 사용자가 명시적으로 release 또는 publish 작업을 요청한 경우에만 `npm publish`를 실행해야 한다고 명확히 했습니다.
- 한국어와 영어 출력, JSON 출력, Markdown 출력, `--init`, `--min-score` 보존 요구사항을 강화했습니다.
- v0.4.0을 위해 `CHANGELOG.md`, `docs/release-checklist.md`, 이 릴리스 노트를 업데이트했습니다.

## 검증

```bash
npm test
npm run check
npm pack --dry-run
```

## 배포

이번 릴리스는 `ai-ready-score@0.4.0`으로 npm에 배포하기 위한 릴리스입니다.
