# v0.5.0 - Configurable Project Checks

This release adds `--config` support so teams can add project-specific AI-readiness checks without changing the built-in 100-point scoring rubric.

## Changes

- Added `--config <file>` for JSON configuration files.
- Added configured checks for required files, required directories, required package scripts, and forbidden files.
- Added optional config `minScore`; CLI `--min-score` still takes precedence when both are provided.
- Added `failOnMissingConfigRequirements` for CI workflows that should fail when configured checks fail.
- Added configured check output to text, JSON, and Markdown reports.
- Kept default scoring behavior stable for users who do not pass `--config`.

## Example

```json
{
  "minScore": 80,
  "failOnMissingConfigRequirements": true,
  "requiredFiles": ["SECURITY.md"],
  "requiredDirectories": ["docs"],
  "requiredPackageScripts": ["lint"],
  "forbiddenFiles": [".env"]
}
```

## Validation

```bash
npm test
npm run check
npm pack --dry-run
```

## Publishing

This release is intended to be published to npm as `ai-ready-score@0.5.0`.

# v0.5.0 - 프로젝트별 설정 검사

이번 릴리스는 기본 100점 점수 기준을 변경하지 않고도 팀별 AI 준비도 요구사항을 추가할 수 있도록 `--config`를 지원합니다.

## 변경 사항

- JSON 설정 파일을 읽는 `--config <file>` 옵션을 추가했습니다.
- 필수 파일, 필수 폴더, 필수 package.json 스크립트, 금지 파일에 대한 설정 검사를 추가했습니다.
- 선택적 설정값 `minScore`를 추가했습니다. CLI의 `--min-score`가 함께 제공되면 CLI 값이 우선합니다.
- 설정 검사 실패 시 CI를 실패시킬 수 있는 `failOnMissingConfigRequirements`를 추가했습니다.
- 텍스트, JSON, Markdown 리포트에 설정 검사 결과를 추가했습니다.
- `--config`를 사용하지 않는 기존 사용자의 기본 점수 동작은 안정적으로 유지했습니다.

## 예시

```json
{
  "minScore": 80,
  "failOnMissingConfigRequirements": true,
  "requiredFiles": ["SECURITY.md"],
  "requiredDirectories": ["docs"],
  "requiredPackageScripts": ["lint"],
  "forbiddenFiles": [".env"]
}
```

## 검증

```bash
npm test
npm run check
npm pack --dry-run
```

## 배포

이번 릴리스는 `ai-ready-score@0.5.0`으로 npm에 배포하기 위한 릴리스입니다.
