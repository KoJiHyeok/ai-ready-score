# v0.1.0 - Initial Release

This is the first public release of `ai-ready-score`.

`ai-ready-score` is a dependency-free Node.js CLI tool that analyzes whether a codebase is easy for AI coding agents to understand, run, modify, and test.

## Features

- AI-readiness score from 0 to 100
- Grade output from A to F
- Korean and English human-readable output
- JSON output for automation
- Markdown report output
- Project documentation checks
- Project structure checks
- package.json script checks
- AGENTS.md checks for AI coding agents
- GitHub and safety readiness checks
- Sensitive root file warnings
- Example good and poor projects
- GitHub Actions CI
- Dependency-free CommonJS implementation
- npm package publishing
- npm package metadata and validation

## Usage

```bash
node bin/ai-ready-score.js .
node bin/ai-ready-score.js . --lang ko
node bin/ai-ready-score.js . --lang en
node bin/ai-ready-score.js . --json
node bin/ai-ready-score.js . --markdown
npx ai-ready-score .
npx ai-ready-score . --lang en
npx ai-ready-score . --json
npx ai-ready-score . --markdown
npm install -g ai-ready-score
ai-ready-score .
```

## Validation

```bash
npm test
npm run check
npm pack --dry-run
```

`ai-ready-score` is now available on npm. npm publishing has been completed for this release; publishing future versions should still happen only after explicit user approval.

# v0.1.0 - 첫 공개 릴리스

`ai-ready-score`의 첫 공개 릴리스입니다.

`ai-ready-score`는 코드베이스가 AI 코딩 에이전트가 이해하고, 실행하고, 수정하고, 테스트하기 쉬운 상태인지 분석하는 의존성 없는 Node.js CLI 도구입니다.

## 주요 기능

- 0점부터 100점까지 AI 준비도 점수 제공
- A부터 F까지 등급 출력
- 한국어와 영어 human-readable 출력
- 자동화를 위한 JSON 출력
- Markdown 리포트 출력
- 프로젝트 문서 점검
- 프로젝트 구조 점검
- package.json 스크립트 점검
- AI 코딩 에이전트를 위한 AGENTS.md 점검
- GitHub 및 보안 준비도 점검
- 프로젝트 루트의 민감 파일 경고
- 좋은 예시 프로젝트와 부족한 예시 프로젝트
- GitHub Actions CI
- 의존성 없는 CommonJS 구현
- npm 패키지 공개
- npm 패키지 메타데이터와 검증 절차
